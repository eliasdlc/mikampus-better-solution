Dos modos, una frontera clara

Desktop local

Para usar desde tu PC. El agente puede seguir aunque cierres la pestaña, pero se detiene si el equipo se duerme, se apaga o pierde conexión.

Ideal para uso diario

Home Server

Para un equipo propio que permanece encendido. Acceso local mediante túnel SSH por defecto; no expongas el puerto a Internet.

Para desarrollo con Node

npx mikampus corre en foreground: cerrar la terminal lo detiene. Requiere Node 24 o superior.

npm install -g mikampus && mikampus install-service

No hay atajos ocultos

  1. Verifica. Compara el SHA-256 del artefacto antes de abrirlo.
  2. Configura. El primer arranque descarga o verifica el browser y luego pide tu cuenta.
  3. Controla. Puedes detener el agente, exportar copias y borrar tus datos cuando quieras.
